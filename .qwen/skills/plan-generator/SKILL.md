# Plan Generator

Automatically creates structured Plan.md files for complex multi-step tasks.

## Usage

### Via Qwen Code

```bash
# Ask Qwen Code to generate a plan
qwen "Generate a plan for processing the task in Needs_Action/FILE_meeting_notes.md"
```

### Via Python Script

```bash
# Generate plan for specific file
python watchers/plan_generator.py ../AI_Employee_Vault FILE_meeting_notes.md

# Generate plans for all pending tasks
python watchers/plan_generator.py ../AI_Employee_Vault --all
```

### Programmatically

```python
from plan_generator import PlanGenerator

generator = PlanGenerator('../AI_Employee_Vault')
plan_path = generator.create_plan(
    task_name='Client Onboarding',
    steps=[
        'Send welcome email',
        'Schedule kickoff meeting',
        'Create project folder',
        'Set up billing'
    ],
    source_file='Needs_Action/FILE_client_inquiry.md'
)
```

## Plan File Format

Generated plans follow this structure:

```markdown
---
type: plan
task: Client Onboarding
created: 2026-03-10T16:00:00
status: in_progress
source_file: FILE_client_inquiry.md
priority: medium
estimated_hours: 4
---

# Plan: Client Onboarding

## Overview
Brief description of what this plan achieves.

## Steps

1. [ ] Send welcome email
   - Template: Use welcome_template_v2
   - Recipient: client@example.com

2. [ ] Schedule kickoff meeting
   - Attendees: Team + Client
   - Duration: 1 hour

3. [ ] Create project folder
   - Location: Projects/ClientName
   - Structure: Standard template

4. [ ] Set up billing
   - Rate: $100/hour
   - Invoice: Monthly

## Progress

- **Started**: 2026-03-10T16:00:00
- **Completed**: -
- **Steps Done**: 0/4
- **Next Step**: Send welcome email

## Resources

- [[Business_Goals]] - Related business objectives
- [[Company_Handbook]] - Company guidelines

## Notes

*Add notes during execution.*

---
*Generated by AI Employee Plan Generator*
```

## Auto-Generation Rules

Plans are automatically generated when:

| Condition | Action |
|-----------|--------|
| Task has 3+ steps | Create Plan.md |
| Task involves multiple files | Create Plan.md |
| Task spans multiple days | Create Plan.md |
| Task requires approval | Create Plan.md |

## Integration with Orchestrator

The orchestrator automatically creates plans for complex tasks:

```python
# In orchestrator.py
if len(steps) >= 3:
    plan_path = plan_generator.create_plan(task_name, steps, action_file)
```

## Commands

### Create Plan from Action File

```bash
python watchers/plan_generator.py ../AI_Employee_Vault \
  --action-file Needs_Action/FILE_project_alpha.md \
  --auto-steps
```

### Update Plan Progress

```bash
python watchers/plan_generator.py ../AI_Employee_Vault \
  --update-plan Plans/PLAN_project_alpha.md \
  --complete-step 1
```

### List All Plans

```bash
python watchers/plan_generator.py ../AI_Employee_Vault --list
```

## Templates

### Simple Task Plan

```markdown
# Plan: {task_name}

## Steps
1. [ ] Step 1
2. [ ] Step 2
3. [ ] Step 3

## Progress
- Steps Done: 0/3
```

### Complex Project Plan

```markdown
# Plan: {task_name}

## Overview
{description}

## Prerequisites
- [ ] Prerequisite 1
- [ ] Prerequisite 2

## Phases

### Phase 1: Planning
1. [ ] Task 1.1
2. [ ] Task 1.2

### Phase 2: Execution
1. [ ] Task 2.1
2. [ ] Task 2.2

### Phase 3: Review
1. [ ] Task 3.1

## Resources
- Link to relevant files

## Timeline
- Start: {date}
- End: {date}
```

## API Reference

### PlanGenerator Class

```python
class PlanGenerator:
    def __init__(self, vault_path: str)
    
    def create_plan(
        self,
        task_name: str,
        steps: list,
        source_file: Path,
        description: str = '',
        priority: str = 'medium'
    ) -> Path
    
    def update_progress(
        self,
        plan_path: Path,
        completed_step: int = None,
        status: str = None
    ) -> bool
    
    def list_plans(self, status: str = None) -> list
```
